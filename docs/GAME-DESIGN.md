## 기본 규칙

- 맵 15 × 13 타일. 타일 크기 옵션 64 / 128 / 256px.
- 기본 제한 시간 180초. 봇 3명, 난이도 쉬움/보통/어려움.
- 물풍선 도화선(FUSE) **2600ms**, 물줄기 잔류(WATER_MS) **480ms**, 갇힘 유지(TRAP_MS) **4000ms** 후 탈락.
- 갇힌 상태에서 물을 다시 맞으면 **즉시 탈락**.
- **터치 팝 (v7, 클래식 규칙)**: 살아있는 엔티티가 갇힌 상대와 `T*0.6` 이내로 접촉하면 즉시
  탈락시킨다. 물 재격 즉사와 병존. 봇 AI에도 '갇힌 상대 사냥' 우선순위가 추가됨
  (위험 탈출 다음, 아이템보다 먼저) — 게임이 더 치열해지는 의도적 밸런스 변화.
- 나무상자 파괴 시 **42%** 확률로 아이템 드랍. 강화상자(tough)는 2회 필요 (1타 → 일반 상자).
- 물풍선 연쇄: 폭발 범위에 다른 풍선이 있으면 즉시 연쇄 폭발.
- 스폰 코너 4곳은 각 3칸 비워둠. 맵 생성 후 BFS로 고립 구역 발견 시 하드블록을 열어 연결 보정.

## 아이템 (클래식 세트)

| 아이템 | 효과 | 상한 |
|---|---|---|
| 물풍선 | 동시 설치 수 +1 | 8 |
| 물줄기 | 폭발 길이 +1 | 8 |
| 롤러블레이드 | 이동 속도 +1 | 7 |
| 바늘 | 내 풍선 즉시 터뜨리기 1회분 | 5 |
| 물풍선 통과 | 풍선 통과 | on/off |
| 블록 통과 | 상자 통과 | on/off |
| 거북이 | 7초간 속도 45% (나쁜 아이템) | — |

이동 속도 공식: `(2.3 + 0.42 * (speed - 1)) * tile * (느림이면 0.45)` px/s.
속도 5 이상이면 잔상 3겹 + 발밑 먼지 파티클.

**레인 이동 어시스트 (v4)**: 한 축으로만 이동할 때 수직 축을 타일 중앙으로 sp 속도로
끌어당겨(축 정렬) 캐릭터가 항상 칸 정중앙 레인을 탄다 — 봄버맨식. 칸 안 상하 유영 제거.
속도 공식·히트박스 반경(0.29T)은 불변, 대각 입력 시엔 비적용.

## AI (BFS 기반)

우선순위:

1. 위험 타일이면 안전 타일로 탈출
2. 좋은 아이템 획득
3. 상자 인접 또는 플레이어 근접 시, **탈출 경로가 확보될 때만** 풍선 설치
4. 상자 쪽 이동
5. 플레이어 추적

재계산 주기: 쉬움 420ms / 보통 220ms / 어려움 130ms. 어려움은 시작 물줄기 2, 속도 4.
수용 기준: 봇이 자기 풍선에 자살하지 않아야 한다.

**생존성 강화 (v4)** — 자멸 현상 원인 3개 봉합:
1. 위험 탈출 시 위험 타일을 밟지 않는 경로 우선 (bfs danger 필터, 불가 시에만 통과 허용)
2. 풍선 설치 판단 시 탈출로가 기존 위험(물줄기·타풍선 폭발권)을 경유하면 설치 포기
   — 자기 폭발선만 통과 허용 (이전엔 무필터라 물로 걸어 들어감)
3. driveBot 스테일 경로 감지: 재계산 주기 사이에 다음 경로 타일이 위험해지면 즉시 재계획

30초 방치 관찰에서 즉사 소멸 확인 (남은 사망은 봇 간 정상 교전).

- **갇힘**: 물방울 14개 + 풍선 흔들림 + 캐릭터 1px 진동 + 기포 상승(160ms 간격), 잔여시간 링(30% 이하 빨강)
