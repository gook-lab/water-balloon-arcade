# 1라운드 QA 회귀 — QA 담당 (리드, 2026-11-26)

공통 규칙: `docs/upgrade/briefs/10-round1.md` 의 「일하는 곳」·「지켜야 할 것」을 따릅니다(포그라운드 + timeout, 넓은 kill 금지, 의존성 추가 금지).
가지 `upgrade/r1` 에 1라운드(엔진 + 화면)가 합쳐져 있습니다(`dc5f82f`). `dist` 는 이 커밋으로 빌드돼 있고, 리드 서버 `http://127.0.0.1:5310` (vite preview) 이 그것을 띄우고 있습니다. 이 서버를 끄거나 다시 띄우지 마세요. 빌드가 필요하면 리드에게 보고로 남깁니다.

## 할 일

1. **QA 스크립트를 새 화면에 맞추기** — `docs/upgrade/qa/*.mjs`. 1단계에서 당신(QA)이 쓴 스크립트가 옛 버튼 이름을 찾다 모든 단계가 타임아웃났습니다(`docs/upgrade/qa/out/logs-r1/*.log`).
   - 바뀐 이름: 타이틀 「게임 시작」→「한 판 하기」, 맵 선택 「입장」→「시작하기」, 결과 「맵 변경」→「맵 바꾸기」 등. `src/screens/*.jsx` · `src/components/ResultOverlay.jsx` · `PauseOverlay.jsx` 를 읽고 실제 이름을 확인합니다.
   - **옛 이름도 계속 받게** 합니다(예: `lib.mjs` 에 이름 후보 목록 → 있는 쪽을 누름). 1단계 기준선(`live` · `local` 라벨)과 같은 스크립트로 비교해야 하기 때문입니다.
   - 새 단계: 게임에 들어가면 3·2·1 카운트다운(`window.__wbaEngine().phase` 가 `'countdown'` → `'playing'`) 동안 입력이 막힙니다. 판을 조작하는 스크립트는 `phase === 'playing'` 까지 기다립니다(`phase` 가 없으면 옛 빌드이니 기다리지 않음). 첫 판 말풍선(`.first-tip`)은 가리지 않는 안내입니다.
   - 판이 끝난 뒤 · 일시정지 상태는 새 오버레이(`.result-overlay`, `.pause-overlay`)입니다.
2. **회귀 실행** — `bash docs/upgrade/qa/run-all.sh http://127.0.0.1:5310 r1` 을 단계별 timeout 안에서 돌립니다(전체가 길면 `run-all.sh` 안의 단계를 하나씩 직접 `timeout` 걸어 실행해도 됩니다). 그 뒤 `node docs/upgrade/qa/summary.mjs --label r1 --base local`.
3. **새 기능 점검(짧게)** — 같은 Playwright 로: Esc 일시정지 → 「계속할게요」로 이어짐, 일시정지 중 판 시계가 멈춤, 결과 화면 첫 버튼 포커스, 「결과 복사」 버튼 존재, 효과음 파일 12개가 200 으로 받아짐(`/sfx/<key>.mp3`), `/og.png` · `/favicon.svg` 200, 390×844 · 844×390 · 1440×900 가로 넘침 0.
4. **보고서** — `docs/upgrade/qa-r1.md`(습니다체, 헤딩은 「대상 — 결정」 명사구). 1단계 `qa-baseline.md` 의 큰 결함 B1~B3 · 작은 결함 S1~S17 각각의 지금 상태(고침 / 그대로 / 다음 라운드로 미룸 / 새로 생김)를 표로, 근거는 out 경로나 수치로. **배포를 막을 결함**(새 오류 · 흐름 깨짐 · 넘침)은 맨 위에 따로 적습니다.
