### U1 첫 판 안내 — 기획 P0-3 그대로

`docs/upgrade/plan.md` 「P0-3」의 무엇을 · 수용 기준을 지킵니다.
- 물줄기 범위 표시(`blastTiles` 를 칸 목록 순수 함수로 분리 → 단위 시험), 터지기 0.6초 전 깜빡임(축소 모션이면 깜빡임 대신 진하게), 설정 「물줄기 범위 보기」(기본 켬, 저장).
- 타이틀 규칙 카드: 터치 팝 한 줄, 아이템 7종 범례(그림 + 한 줄), 맵 수 바로잡기(QA S8).
- 첫 판 말풍선 「스페이스로 물풍선을 놓고 옆으로 피해요」 — 한 번만. 기록 여부는 자기 키(`wba-seen-tip`)로 판단해 엔진 담당의 `records.js` 를 기다리지 않습니다.
- 타이틀 기록 한 줄: 엔진 담당이 `src/records.js` 에 요약 함수를 내보냅니다. 아직 없으면 자리만 만들고 최종 보고에 적어 두세요(리드가 합칠 때 연결).

### U2 휴대폰 — 안내 + 화면 깨짐 (사용자 결정: 터치 조작은 다음 라운드)

- QA B2: 굵은 포인터(터치) 기기로 열면 타이틀에 「키보드가 있는 컴퓨터에서 해요」 안내 + 「링크 복사」. 그래도 들어가 볼 수 있게 막지는 않습니다.
- QA S1 · S2 · S3: 게임 화면은 맨 위에서 시작, 세로 타이틀 가로 넘침 0, 좁은 결과 버튼 글자 한 줄(결과 화면 CSS 는 `styles.css` 라 화면 담당).
- 390×844 · 844×390 · 1440×900 에서 가로 넘침 0 을 촬영으로 확인.

### U3 키보드 · 보조기술 — QA B3 · S10 · S11

- 캐릭터 · 맵 카드를 Tab 으로 닿고 Enter/Space · 화살표로 고르기(라디오 그룹 의미: `role="radiogroup"` + `aria-checked`, 또는 진짜 버튼 + `aria-pressed`).
- 축소 모션이면 떠다니는 · 튀는 애니메이션 정지(S10).
- 화면마다 `h1`, `main`, 캔버스 이름(`aria-label`)(S11).

### U4 문구 · 설명 바로잡기 — 마케팅 「게임 안 문구」 + QA S8 · S9

- 타이틀 · 선택 화면 문구를 마케팅 표대로(결과 화면 문구는 엔진 담당).
- 게임에 없는 기능을 약속하는 설명 고치기: 눈 언덕 「빙판」, 펭구 「튼튼」, 고철 공장 「대각선 벽 · 시야가 좁음」(실제는 벽이 거의 열림 — S9) → 실제와 맞는 말로. 규칙은 바꾸지 않습니다.

### U5 첫인상 — 메타 · 파비콘 · 집계 · 폰트

- `index.html`: description · og(title · description · image · url · site_name=물풍선 대작전) · twitter card · theme-color · 파비콘 링크. 그림 파일 이름은 `/og.png`(1200×630) · `/favicon.svg` · `/favicon-32.png` · `/apple-touch-icon.png`(180) 로 정해 두고 연결만 합니다 — 마케팅 담당이 최종 그림을 만들고 리드가 `public/` 에 넣습니다. 그 전까지는 지금 타이틀 화면 촬영으로 임시 `og.png` 를 둬도 됩니다.
- 방문 집계: `<script defer src="/_vercel/insights/script.js"></script>`(의존성 없이, Vercel 이 제공). 로컬에서 404 여도 오류가 화면에 안 보이게.
- QA S13: 거의 안 쓰는 폴백 웹폰트(Jua · Gothic A1) 로드 제거.
