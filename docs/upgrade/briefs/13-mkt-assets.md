## 만들 것

1. **OG 그림** `og.png` 1200×630 — 연출 장면을 실제 게임에서 다시 찍어(봇 판 · `?bots=` · Playwright) 1단계 시안 방향으로 최종본. 글자는 게임 이름 + 훅 한 줄까지만, 작게 보여도 읽히게. 다른 게임 이름 · 그림 금지.
2. **파비콘** `favicon.svg`(픽셀 물풍선 하나, 게임 팔레트) · `favicon-32.png` · `apple-touch-icon.png`(180×180, 여백 있게).
3. **허브 카드 표지** `hub-cover.png` 800×500 — 진열장 크기(약 360px 폭)에서 어떤 게임인지 보이게(설정 버튼 가득한 타이틀 화면 말고 플레이 장면). 리드가 허브에 넣습니다.
4. **문구 묶음** `copy.md` —
   - 메타: `<title>`, description(한국어 80자 안팎), og:description(한 · 영), twitter 같은 값.
   - 허브 카드: 후크 · 소개(한 · 영) — 지금 허브 문구와 바꿀 표(맵 수는 일곱 + 랜덤).
   - 결과 공유 한 줄 형식(엔진 담당이 쓰는 「결과 복사」) — 승 · 패 · 무 세 경우.
5. **README 첫 단락 대체 문안**(한 · 영) — 다른 게임 지칭 없이. 화면 담당이 README 를 고칠 때 쓰니, 늦지 않게 `copy.md` 맨 위에 먼저 써 두세요.

촬영본 · 최종 그림은 모두 이 폴더에. 그림은 1280px 이하로 Read 해서 직접 확인합니다(작은 크기에서 읽히는지 360px 축소본도 같이 봅니다).
